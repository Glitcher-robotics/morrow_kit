질문 예시① 같은 ID 두 행은 재전송인가 상태 갱신인가? 중복 키·최신 기준이 무엇인가? 원문을 남겨야 하나?
질문 예시② ‘최근’ 기준 시각·시간대·구간 끝 포함 여부는? 기간 이전 미완료는 어떻게 보나? 빈 값·미등록은 어디에 표시하나?

놓치기 쉬운 가정 예④ README의 ‘전체’가 파일 전체인가 조회 기간인가? 샘플에 없는 빈 값·ID 중복·재측정·재전송이 실제에는 있는가?
놓치기 쉬운 가정 예⑤ README의 추천 산식·정렬과 실제 판단이 같은가? 타임존·단위·상태 이력이 일치하나? 목록에 없는 대상·기록 오류를 제외해도 되나?
예시는 고의 은폐의 증거가 아닌 확인 후보다. 지정 실행 지시는 지키고 업무 가정은 데이터·담당자 답과 대조한다.
실제 사례→현재 처리→빈도·시간·실패 비용→판단·예외 순서. README에 없는 독립 질문 3~5개부터, 전체 후보 최대 7개. 해법을 유도하지 않는다.
