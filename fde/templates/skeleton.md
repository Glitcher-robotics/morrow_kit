# 처리 뼈대 — 사람 확인용 초안 (METHOD)
참고: 저장소 docs/METHOD.md, 설치 후 fde/docs/METHOD.md. 6처리단계는 7 STATE와 별개이며 파일 6개를 강제하지 않는다. AI 초안을 사람이 확정한다.

범위/버전 __ / 실제 검토자·확인 시각 __ / 기준 시각·자동/직접·시간대·근거 __ / 이후 사건 처리 __
파일 __ / 헤더·빈 레코드 규칙 __ / 원본 ID __ / 배타적 보존: 입력 N(__)=정상 대표 V(__)+격리 원본 Q(__)+중복 원본 D(__) / 검사·로그 __
격리 경고는 정상에 재집계하지 않는다. 파싱 실패로 N을 모르면 미확정. 다른 파일·단계 경고·설비 수는 식에 더하지 않는다. 등급 미상과 필수 상태 오류는 구분한다.
고정 입력·시점·정답 이야기 REQ __ / 함정·경계·안전 REQ __. 합격 문장 원본=requirements, 답 원문=interview, 결정표=decisions. 중복 기준을 만들지 않는다.
기존 예산 안에서 작성: 80분 구조 동결·140분 새 기능 동결·170분 제출. 설정도 검사하고 계약 변경은 동결 뒤 기본 보류. 안전·핵심 오류·확인된 필수 변경은 이유 기록·최소 수정·재검증.
